Stochastic Provenance

A Systems Primitive for Semantics-Preserving Multi-Trajectory Inference

Roberto Márcio Braga

Read the full preprint (PDF)Source codeCitation

Abstract

When language-model inference branches from a shared prefix, deterministic state can be reused without reusing random draws. Reusing the draws can change how trajectories behave together, even if individual sampling distributions remain unchanged. This work studies when prefix reuse preserves each trajectory’s token decisions and measures when it saves time or memory.

Method

A shared-prefill continuation and a serial batch-1 semantic reference received the same path-local Philox draws. The matrix crossed Qwen3-0.6B, Qwen3-4B and Phi-4-mini with strict eager and operational SDPA, using four prompts, eight trajectories per prompt and 64 decoding steps per model-policy cell. The timing comparison instead used a baseline that duplicated the prefix across the batch, on one RTX 5060 Ti.

Results

All 192 trajectories and all 12,288 token decisions matched in the tested semantic matrix. In all six negative-control cells, sharing one random stream across four paths collapsed four distinct trajectories to one.

Qwen3-0.6B, 16 decode tokens
2.04× wall-time ratio (baseline ÷ shared); 46.7% less peak allocated VRAM.
Phi-4-mini, 64 decode tokens
0.59× wall-time ratio (baseline ÷ shared); 28.2% less peak allocated VRAM. Median wall time rose from 15.39 s to 26.21 s.

Limitations and reproduction

Exact agreement was observed in the tested matrix, not guaranteed across hardware, dtypes, backends or inputs. The selected timings are controlled harness measurements, not a production serving-engine comparison or a general speedup. Peak allocated VRAM is not whole-device usage or energy consumption. The dependency-free CPU demo checks semantics, not GPU latency.
